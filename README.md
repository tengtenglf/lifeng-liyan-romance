# 丰艳的浪漫小宇宙

李丰与杨立艳的婚纱影像与互动收藏网站。

**在线查看：https://tengtenglf.github.io/lifeng-liyan-romance/**

持有链接即可直接访问，无需登录。网站通过 GitHub Pages 发布，不发布到论坛或市场进行推广。

包含18枚动态表情、12张心动签、情侣默契小游戏、水彩晕染展示、动态展示卡及分享小卡。

本地使用：下载仓库，打开 index.html，并保留 assets 和 downloads 目录。收藏只保存在当前浏览器，游戏答案不上传服务器。

本仓库仅包含网站成品，没有上传相机原片、底片及制作缓存。照片、影像、插画保留各自权利；字体许可见 assets/OFL.txt。
